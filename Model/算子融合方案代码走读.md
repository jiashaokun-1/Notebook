```
TransformContext (含 model_id + FusionConfig)
        │
        ▼
FusionPass.run(graph, ctx)                      ← api.py
        │
        ├─ 1. load_platform_rules(model_id)     ← platforms/__init__.py
        │     ├─ clear_rules()
        │     ├─ import_builtin_rules()         ← builtins.py
        │     ├─ load_model_yaml_rules()        ← yaml_loader.py（解析 rules/*.yaml → register_rule）
        │     └─ legacy platform .py rules
        │
        ├─ 2. resolve_fusion_config(...)        ← yaml_loader.py
        │     按 model_slug + phase 在 configs/ 下查 yaml → FusionConfig
        │
        └─ 3. fuse(graph, ctx)                  ← algorithm.py
              ├─ iter_active_rules(cfg, phase)  ← registry.py（按 enable/disable + default_phases 过滤）
              ├─ bucket_into_groups(graph)      ← algorithm.py（按 call_id 切桶）
              │
              └─ for each group:
                    rule = lookup_rule(seq, module_class, active_rules)   ← registry.py
                          └─ best_rule(...)                               ← match.py
                                ├─ _match_class_only      ← 检查桶大小
                                ├─ _match_ordered_regex   ← 双指针匹配 op 序列

                            ├─ resolve_io                 ← provenance.py
```

## 阶段 1：入口 `FusionPass.run`

**文件**：[python/zrt/transform/fusion/api.py](python/zrt/transform/fusion/api.py)

整个融合系统对 pipeline 的唯一入口。它做三件事：加载规则注册表、决定 FusionConfig、调 `fuse()`。

```python
def run(self, graph: "OpGraph", ctx: "TransformContext") -> "OpGraph":
    from python.zrt.transform.context import FusionConfig
    from python.zrt.transform.fusion.algorithm import fuse
    from python.zrt.transform.fusion.platforms import load_platform_rules
    from python.zrt.transform.fusion.yaml_loader import resolve_fusion_config

    load_platform_rules(getattr(ctx, "model_id", "") or "")     # ① 注册 builtin + 模型 yaml 规则

    existing = getattr(ctx, "fusion", None)
    is_default = (
        existing is None
        or (existing.enabled_rules is None
            and not existing.disabled_rules
            and not existing.allow_structural_collapse
            and not existing.merge_sibling_classes)
    )
    if is_default:                                              # ② CLI 没提供 → 自动按 model+phase 查 yaml
        phase = ctx.phase_for_fusion() if ctx is not None else "inference"
        ctx.fusion = resolve_fusion_config(
            getattr(ctx, "model_id", "") or "", phase, explicit_path=None,
        )
    return fuse(graph, ctx)                                     # ③ 真正干活
```

**关键设计点**：CLI/测试如果已经显式塞了 `FusionConfig`（`enabled_rules` 非 None / `disabled_rules` 非空 / 任一开关打开），就跳过自动查找——尊重调用方意图。否则按 model_id 自动落盘加载。

### `register_rule` 的唯一性校验

[registry.py:42](python/zrt/transform/fusion/registry.py)：

```python
_ALL_RULES: list[ModuleFusionRule] = []
_CLASS_INDEX: dict[str, list[ModuleFusionRule]] = {}    # 按类名快速过滤
_NAME_INDEX: dict[str, ModuleFusionRule] = {}            # 按 name 唯一索引

def register_rule(rule: ModuleFusionRule) -> None:
    name = rule.name or rule.op_type or ""
    if not name:
        raise ValueError("ModuleFusionRule has no name and no op_type")
    if name in _NAME_INDEX and _NAME_INDEX[name] is not rule:
        raise ValueError(f"Duplicate fusion rule name {name!r}")
    _ALL_RULES.append(rule)
    _NAME_INDEX[name] = rule
    for key in _index_keys(rule):
        _CLASS_INDEX.setdefault(key, []).append(rule)
```

注册完后，`_ALL_RULES` 是一条按注册顺序排列的有序列表，`_NAME_INDEX` 是 enable/disable 用的 hash 表。

## 阶段 4：active 规则集计算（`iter_active_rules`）

**文件**：[registry.py:135](python/zrt/transform/fusion/registry.py)

把 `FusionConfig` + 当前 phase 翻译成"本次允许触发的规则列表"：

```python
def iter_active_rules(fusion_cfg, phase) -> list[ModuleFusionRule]:
    enabled = fusion_cfg.enabled_rules
    disabled = set(fusion_cfg.disabled_rules)

    if enabled is None:
        # 走默认：每条规则的 default_phases 包含当前 phase 才进候选集
        candidates = [r for r in _ALL_RULES if phase in r.default_phases]
    else:
        # 严格白名单：未注册的 name 直接抛错（防拼写）
        unknown_enabled = [n for n in enabled if n not in _NAME_INDEX]
        if unknown_enabled:
            raise ValueError(f"Unknown fusion rule names in enabled_rules: {unknown_enabled}.")
        candidates = [_NAME_INDEX[n] for n in enabled]

    # disabled 宽松：不存在的 name 视为 no-op（全局 fallback YAML 可能列模型专属规则）
    return [r for r in candidates if r.name not in disabled]
```

**两类校验严格度不同**：
- `enabled_rules`（白名单）：拼错就报错——你说"只开 X"，X 不存在那肯定是配置 bug。
- `disabled_rules`（黑名单）：拼错降级 debug log——`training_default.yaml` 列的 `kv_compressor` 在跑 LLaMA 时根本没注册，跳过即可。

## 阶段 5：算子分桶（`bucket_into_groups`）

**文件**：[algorithm.py:66](python/zrt/transform/fusion/algorithm.py)

按"forward 调用实例"切桶，**不再**按 (scope, module_class, layer) 切——这是上一轮修 row 36 错误的根本：

```python
def bucket_nodes_by_leaf_module(graph) -> list[FusionGroup]:
    groups, current, last_key = [], None, None

    for node in graph.topo_sort():
        if node.category == "communication" or not node.scope:    # comm/无 scope → 单独成桶并打断
            groups.append(FusionGroup(..., child_ops=[node], call_id=..., is_full_forward=False))
            current, last_key = None, None
            continue

        node_call_id = getattr(node, "call_id", 0) or 0
        if node_call_id > 0:
            key = ("call", node_call_id)                          # ★ 主路径：按 call_id
        else:
            key = ("legacy", node.scope, node.module_class, node.layer)  # ★ 兜底：torch.compile 无 call_id

        if current is not None and key == last_key:
            current.child_ops.append(node)
        else:
            current = FusionGroup(..., child_ops=[node], call_id=node_call_id)
            groups.append(current)
        last_key = key

    # ★ 关键：标记是否"完整 forward 调用" — class_only 规则的合法触发条件
    if any(g.call_id > 0 for g in groups):
        call_id_total = {}
        for n in graph.nodes.values():
            cid = getattr(n, "call_id", 0) or 0
            if cid:
                call_id_total[cid] = call_id_total.get(cid, 0) + 1
        for g in groups:
            if g.call_id > 0 and len(g.child_ops) == call_id_total.get(g.call_id, -1):
                g.is_full_forward = True
    return groups
```

**`is_full_forward` 的判定**：当 graph 里所有打着 `call_id=K` 的 op 都落在同一个 bucket 里（没有被子模块调用切碎），那这个 bucket 就是 K 这次 forward 调用的完整切片。这是 `class_only` 规则唯一允许触发的情况——`Attention` 这种语义封装必须看到整个 forward 才能贴标签，看到一个 inline 片段就贴是 row 36 的 bug。

## 阶段 6：规则匹配（`lookup_rule` → `best_rule`）

**文件**：[registry.py:71](python/zrt/transform/fusion/registry.py) + [match.py:148](python/zrt/transform/fusion/match.py)

```python
def lookup_rule(op_types, *, module_class=None, active_rules=None):
    # 候选集 = active_rules（FusionConfig 过滤后的）∩ _CLASS_INDEX[module_class]
    candidates_global = active_rules if active_rules is not None else _ALL_RULES
    if module_class:
        narrowed_all = _CLASS_INDEX.get(module_class, [])
        if active_rules is not None:
            active_set = set(map(id, active_rules))
            narrowed = [r for r in narrowed_all if id(r) in active_set]
        else:
            narrowed = narrowed_all
        rule = best_rule(op_types, module_class, narrowed)         # ① 类名精确索引快路径
        if rule is not None:
            return rule
    return best_rule(op_types, module_class or "", candidates_global)  # ② 兜底全量遍历（覆盖正则 target_class）
```

`best_rule` 在候选集里挑 priority 最高的（[match.py:148](python/zrt/transform/fusion/match.py)）：

```python
def best_rule(op_types, module_class, rules) -> Optional[ModuleFusionRule]:
    best, best_idx = None, -1
    for idx, rule in enumerate(rules):
        if rule.pattern is None:
            continue
        if not match_group(op_types, module_class,
                           pattern=rule.pattern, target_class=rule.target_class):
            continue
        if best is None or rule.priority > best.priority:
            best = rule
    return best
```

`match_group` 是三档分发器（[match.py:127](python/zrt/transform/fusion/match.py)）：

```python
def match_group(op_types, module_class, *, pattern, target_class) -> bool:
    if not _class_matches(module_class, target_class):    # 先 class 校验
        return False
    if pattern.kind == "class_only":     return _match_class_only(op_types, pattern)
    if pattern.kind == "ordered_regex":  return _match_ordered_regex(op_types, pattern)
    if pattern.kind == "dag_signature":  return _match_dag_signature(op_types, pattern)
```

### 三档匹配实现

**A. `class_only`**（仅校验 group size）：

```python
def _match_class_only(op_types, pattern) -> bool:
    return pattern.min_ops <= len(op_types) <= pattern.max_ops
```

**B. `ordered_regex`**（双指针，跳过 transparent op）：

```python
def _match_ordered_regex(op_types, pattern) -> bool:
    if not _check_size(op_types, pattern): return False
    regexes, skip = pattern.op_regexes, pattern.skip_ops
    i, j = 0, 0
    while i < len(regexes) and j < len(op_types):
        op = op_types[j]
        hit = re.fullmatch(regexes[i], op) is not None
        if hit:        i, j = i + 1, j + 1
        elif op in skip: j += 1                  # view/reshape/_to_copy 等可跳过
        else:          return False
    if i != len(regexes): return False           # 还有 regex 没耗完 → 失败
    while j < len(op_types):                      # 尾部剩余只能是 skip op
        if op_types[j] not in skip: return False
        j += 1
    return True
```

**C. `dag_signature`**（顺序无关的多重集计数）：

```python
def _match_dag_signature(op_types, pattern) -> bool:
    if not _check_size(op_types, pattern): return False
    for regex, min_count in pattern.op_multiset:
        count = sum(1 for op in op_types if re.fullmatch(regex, op))
        if count < min_count: return False
    return True
```

DSV4 的 FP8 `Linear` 用的就是 `dag_signature`：因为 act_quant 引入的 mm/abs/amax/clamp_min/div 顺序在不同 PyTorch 版本上有 ~40 种排列，强序等价比对没法稳定匹配，只能数算子多重集。

## 阶段 7：核心调度循环 `fuse()`

**文件**：[algorithm.py:413](python/zrt/transform/fusion/algorithm.py)

把上面所有零件串起来：

```python
def fuse(graph: "OpGraph", ctx=None) -> "OpGraph":
    fusion_cfg = getattr(ctx, "fusion", None) or FusionConfig()
    phase = ctx.phase_for_fusion() if ctx else "inference"
    active = iter_active_rules(fusion_cfg, phase)         # ① 算 active 规则集
    active_names = {r.name for r in active}

    g = graph.clone()                                     # ② 不修改入参
    groups = bucket_into_groups(
        g, merge_sibling_classes=set(fusion_cfg.merge_sibling_classes),
    )                                                     # ③ 分桶
    fuse_idx = 0

    for group in groups:
        # ─ 单算子桶：只在 class_only 规则 + is_full_forward 时融合
        if len(group.child_ops) <= 1:
            node = group.child_ops[0]
            if node.category == "communication" or not node.module_class:
                continue
            rule = lookup_rule((node.op_type,), module_class=node.module_class,
                               active_rules=active)
            if rule is None: continue
            if rule.pattern is None or rule.pattern.kind != "class_only": continue
            if not group.is_full_forward: continue        # ★ 片段不允许 class_only
            fused = build_fused_node(group, rule, g, fuse_idx); fuse_idx += 1
            g.replace_subgraph({node.id}, fused)
            continue

        # ─ 多算子桶
        if not group.scope or not group.module_class: continue
        actual_seq = tuple(op.op_type for op in group.child_ops)
        rule = lookup_rule(actual_seq, module_class=group.module_class,
                           active_rules=active)
        # ★ class_only 在多算子桶上同样要求 is_full_forward（防 row 36 bug）
        if (rule is not None and rule.pattern is not None
                and rule.pattern.kind == "class_only"
                and not group.is_full_forward):
            rule = None

        group_ids = {op.id for op in group.child_ops}
        if rule is not None:
            replacement = build_fused_node(group, rule, g, fuse_idx)
        elif fusion_cfg.allow_structural_collapse:        # 历史兼容兜底，默认关
            replacement = _build_collapsed_node(group, g, fuse_idx)
        else:
            continue                                      # ★ 没规则就保持 raw aten
        fuse_idx += 1
        g.replace_subgraph(group_ids, replacement)

    if _ADD_NORM_RULE_NAME in active_names:               # ④ Add+Norm 后处理也是命名规则
        g = _compose_add_norm(g)
    return g
```

**两道闸门让 row 36 这种 bug 不再发生**：
1. `class_only` 必须搭配 `is_full_forward=True`——inline 片段直接拒绝。
2. 没匹配规则的桶**默认不再 collapse**，保持 raw aten——以前 `_build_collapsed_node` 把片段塌成 `op_type=module_class` 是错配的根源。

## 阶段 8：融合节点构造 `build_fused_node`

**文件**：[algorithm.py:275](python/zrt/transform/fusion/algorithm.py)

```python
def build_fused_node(group, rule, graph, fuse_idx) -> "OpNode":
    first = group.child_ops[0]
    op_type = rule.op_type or (rule.target_class.__name__ if isinstance(rule.target_class, type)
                                                          else str(rule.target_class))
    fused_from = list(dict.fromkeys(op.op_type for op in group.child_ops))   # 去重 + 保序

    group_ids = {op.id for op in group.child_ops}
    ext_inputs, ext_outputs = _external_io(graph, group_ids)                 # ① 外部 IO

    provenance_parts = []                                                    # ② 角色化 IO
    for spec in rule.inputs:
        port = resolve_io(group.child_ops, spec)
        if port is not None: provenance_parts.append(port)
    for spec in rule.outputs:
        port = resolve_io(group.child_ops, spec)
        if port is not None: provenance_parts.append(port)

    propagated = _propagated_annotations(group)                              # ③ 子节点共识 annotation

    node = OpNode(
        id=f"fused_{fuse_idx}_{first.id}",
        op_type=op_type, inputs=ext_inputs, outputs=ext_outputs,
        scope=group.scope, category=first.category,
        module_class=group.module_class, layer=first.layer,
        component=first.component, fused_from=fused_from,
        num_sub_ops=len(group.child_ops),
        fusion_level="parent" if len(group.child_ops) > 3 else "leaf",
        name=group.leaf_attr,                                                # 给 Excel 看的友好名
        provenance=tuple(provenance_parts),
    )
    node.annotations.update(propagated)
    node.annotations.update(rule.annotations)
    node.annotations["source_op_ids"] = [op.id for op in group.child_ops]    # ④ 给 Excel 显示 Raw Op IDs
    node.annotations["fused_by_rule"] = rule.name                            # ⑤ Rule Name 列
    annotate_fused_node(node, group.child_ops, rule)                         # ⑥ FLOPs/memory 公式求值
    return node
```

### 步骤 ①：外部 IO 推导（`_external_io`）

```python
def _external_io(graph, group_ids):
    inputs, outputs, seen_in, seen_out = [], [], set(), set()
    for e in graph.edges:
        if e.src not in group_ids and e.dst in group_ids:        # 入边
            key = (e.tensor_id, e.dst_idx)
            if key not in seen_in and e.tensor is not None:
                seen_in.add(key); inputs.append(e.tensor)
        if e.src in group_ids and e.dst not in group_ids:        # 出边
            key = (e.tensor_id, e.src_idx)
            if key not in seen_out and e.tensor is not None:
                seen_out.add(key); outputs.append(e.tensor)
    return inputs, outputs
```

桶内部的边在融合后会被 `replace_subgraph` 丢弃，只保留跨桶的 IO 张量作为新节点的 input/output。

### 步骤 ②：角色化 IO 抽取（`provenance.py:resolve_io`）

YAML 里写 `io_roles: - {role: activation, source_kind: input, source_op_index: 0, source_arg_index: 0}` 表示"激活张量取自第 0 个子算子的第 0 个输入"。`resolve_io` 把这个抽象规约映射到具体 OpNode 的 TensorMeta：

```python
def resolve_io(child_ops: list[OpNode], spec: IORole) -> Optional[FusedIOPort]:
    op = child_ops[spec.source_op_index]                # 0=第一个，-1=最后一个
    if spec.source_kind == "input":
        if spec.source_arg_index < len(op.inputs):
            tensor = op.inputs[spec.source_arg_index]
        else: return None
    else:                                                # output
        idx = spec.source_arg_index if spec.source_arg_index >= 0 else -1
        tensor = op.outputs[idx]
    return FusedIOPort(role=spec.role, tensor=tensor, shape_role=spec.shape_role, ...)
```

### 步骤 ③：共识 annotation 传播

```python
_SCALAR_PROPAGATE_KEYS = ("stage_id", "phase", "ep_experts_local", "ep_a2a_inserted", "recompute")
_DICT_PROPAGATE_KEYS = ("tp_split", "ep_needs_a2a", "cp_split")

def _propagated_annotations(group) -> dict:
    propagated = {}
    for key in _SCALAR_PROPAGATE_KEYS:
        vals = {op.annotations.get(key) for op in group.child_ops if key in op.annotations}
        if len(vals) == 1: propagated[key] = vals.pop()       # 全员一致才传
    for key in _DICT_PROPAGATE_KEYS:
        seen = [op.annotations[key] for op in group.child_ops if key in op.annotations]
        if seen and all(d == seen[0] for d in seen): propagated[key] = seen[0]
    return propagated
```

只有所有子节点都同意（pp 段、tp 切分等）才写到融合节点上——避免给 fused 节点贴上"半对半错"的并行标签。

## 阶段 9：Add+Norm 二次合并

**文件**：[algorithm.py:513](python/zrt/transform/fusion/algorithm.py)

唯一一个跨 bucket 的合并，且必须发生在 fuse 之后（因为它合的是已经融合好的 RMSNorm 节点和它前面的 add）。设计上挂在虚拟规则 `"add_norm"` 名下，方便用户禁用：

```python
def _compose_add_norm(graph) -> "OpGraph":
    topo = graph.topo_sort()
    norm_types = {"rms_norm", "layer_norm", "RMSNorm", "LayerNorm"}
    add_types = {"add", "residual_add"}

    pairs = []
    for i in range(len(topo) - 1):
        a, b = topo[i], topo[i + 1]
        if (a.op_type.lower() in add_types or a.op_type.lower().endswith("add")) and \
           (b.op_type.lower() in norm_types or b.op_type.lower().endswith("norm")):
            if any(e.src == a.id and e.dst == b.id for e in graph.edges):
                pairs.append((i, i + 1))

    used = set()
    for add_i, norm_i in reversed(pairs):
        add_node, norm_node = topo[add_i], topo[norm_i]
        if add_node.id in used or norm_node.id in used: continue
        merged = OpNode(
            id=f"composed_{add_node.id}_{norm_node.id}",
            op_type="AddNorm",
            inputs=add_node.inputs, outputs=norm_node.outputs,
            scope=norm_node.scope, ...
        )
        merged.annotations["source_op_ids"] = (
            list(add_node.annotations.get("source_op_ids", [add_node.id]))
            + list(norm_node.annotations.get("source_op_ids", [norm_node.id]))
        )
        merged.annotations["fused_by_rule"] = "add_norm"
        graph.replace_subgraph({add_node.id, norm_node.id}, merged)
        used.add(add_node.id); used.add(norm_node.id)
    return graph
```
